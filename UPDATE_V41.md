# Crypto Regime Manager V45.0.0 — Unified Decision & Quality Workspace

V41 makes the Dashboard the canonical daily workspace and fixes display faults found in live use.

- One page combines trading recommendation, allocation, DCA settings, portfolio/market context, synchronisation, 3Commas/workflow health, active issues and UI quality.
- One navigation owner removes duplicate and legacy menus.
- System Health replaces the old Strategy Health shell.
- Bots uses the same shared layout as the Dashboard.
- Portfolio uses explicit quote currency codes such as USDT rather than a dollar symbol.
- UI Health detects stale visible versions, multiple menus and legacy navigation.
- Cloud Reliability validates the current four-workflow architecture.
- GitHub Actions ignores retired historical workflow names as active faults.
- 3Commas balance polling uses a longer quota guard while bots/deals continue hourly.

Trading remains read-only and all live actions require manual approval.
