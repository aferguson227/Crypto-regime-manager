PROJECT CLEANUP GUIDE

Safe to delete after verifying V21:
- Repeated nested project copies inside data\data, data\data\data, etc.
- __pycache__ folders and *.pyc files.
- Old extracted Easy Update folders (keep the ZIP elsewhere if desired).
- Old temporary upload ZIPs stored inside the repository.
- Duplicate README_V*.md and UPDATE_V*.md files can be moved to an archive outside the repository; keep README.md, ARCHITECTURE.md and the current release notes.

Do NOT delete:
- .git
- top-level data folder itself
- top-level data\TELUSDT_4H.csv, TAOUSDT_4H.csv, SUIUSDT_4H.csv
- config.json
- docs\candidate_registry.json
- docs\health_history.json
- docs\strategies.json
- docs\threecommas.json
- scripts
- .github\workflows

Recommended first cleanup action:
1. Make a full external ZIP backup.
2. Delete only the nested folder C:\Crypto\Projects\data\data (not C:\Crypto\Projects\data).
3. Run the workflow and verify all three assets.
4. Remove __pycache__ folders.
5. Keep backups outside the Git repository, for example C:\Crypto\Backups.
