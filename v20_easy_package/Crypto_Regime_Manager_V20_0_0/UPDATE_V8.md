# Updating to V8

1. Fetch and pull the latest repository in GitHub Desktop.
2. Keep `.git`, `data`, and `threecommas_private_setup` unchanged.
3. Copy the V8 package files over the repository and replace existing code files.
4. Commit with `Add Strategy Evolution Engine V8` and push.
5. Run **Update Crypto Regime Manager**.
6. Open `evolution.html`.
