# Crypto Regime Manager V32.2.0

## Operating State Engine

V32.2.0 introduces a canonical, immutable, read-only operating-state snapshot at `docs/operating_state.json` and a transparent Operating State page.

It reconciles current KuCoin strategy/regime evidence, production decision intelligence, live 3Commas bot/deal observations, configuration differences, capital fields and Kraken/Q1 validation availability. Unknown capital is reported as unknown rather than estimated.

No live bot, order, setting or fund mutation capability has been added. Every recommendation remains advisory and requires manual approval.
