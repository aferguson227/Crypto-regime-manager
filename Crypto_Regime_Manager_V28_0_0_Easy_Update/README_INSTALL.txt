CRYPTO REGIME MANAGER V28.0.0 — EASY UPDATE

1. Place the extracted V28 update folder directly inside your existing Crypto Regime Manager project folder.
2. Double-click INSTALL_V28_EASY.bat.
3. Commit and push the installed files to GitHub.
4. Run the “V28 Autonomous Crypto Regime Refresh” workflow once.
5. Open Cloud Refresh, Discovery and Validation to verify the new pages.
