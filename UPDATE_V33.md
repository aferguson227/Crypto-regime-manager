# V33.0.0 — Trading Command Centre

V33 introduces `command_state.json`, a single immutable, read-only command snapshot combining Market, Operating State, Capital, Portfolio, Recommendation, Adaptive, Outcome, Cloud Reliability and diagnostics evidence. The redesigned Trading Command Centre presents the priority queue, current market and portfolio context, governed actions, risks, evidence and source health in one place.

No live trading capability is added. All deployment decisions remain advisory and require manual approval.
