CRYPTO REGIME MANAGER V27.0.0 — EASY UPDATE

1. Place the extracted V27 update folder directly inside your existing Crypto Regime Manager project folder.
2. Double-click INSTALL_V27_EASY.bat.
3. Commit and push the installed files to GitHub.
4. Run the “V27 Autonomous Crypto Regime Refresh” workflow once.
5. Open Cloud Refresh, Discovery and Validation to verify the new pages.

The installer creates a backup. Live trading, automatic DCA changes and automatic production promotion remain disabled.
