# V22.0.0 — Decision Intelligence

V22 combines the required Research Queue display repair with the next planned Decision Intelligence milestone.

## Main changes

- Rebuilt the Automatic Research Queue in the same dark, mobile-first design language as the dashboard and cockpit.
- Removed the page-specific typography conflict that caused black serif text on a light background.
- Added compact candidate cards, evidence-confidence badges and clearer status colours.
- Added the research lifecycle: Idea → Diagnostic → Candidate → Forward test → Review → Approved → Production.
- Added a prominent winning-candidate summary and collapsible alternative experiments.
- Added clearer metrics for net improvement, duration reduction, drawdown change, deal retention and problem-trade resolution.
- Added explicit manual-action panels and promotion safeguards.
- Updated application and generated-data version labels to V22.0.0.

## Safety policy

V22 remains read-only and advisory. It does not automatically alter production bots, DCA settings, entries or exits. Every candidate still requires independent forward evidence and manual approval.
