# Crypto Regime Manager V17.0.0

V17 is a combined operator-efficiency release built on V16. It preserves all trading, DCA, entry, exit and forward-validation logic.

## Combined improvements

- Compact portfolio-status summary with production, research, entry, replay and alert counts.
- Prioritised severity-based action queue.
- Sticky asset jump navigation for mobile use.
- Stronger visual separation of production and research assets.
- Prominent opportunity score with a visual bar and plain-language posture.
- Collapsible evidence and caution sections to reduce scrolling.
- Portfolio posture generated by the engine: READY, STABLE, REVIEW or ACTION REQUIRED.
- Existing manual approval, immutable candidates and independent forward evidence are unchanged.

## Safety

V17 remains read-only. It does not authorise live execution or change bots, DCA settings or exit policies.
