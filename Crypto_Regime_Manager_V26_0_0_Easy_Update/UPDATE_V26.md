# Crypto Regime Manager V26.0.0

## Included
- Consistent browser-local timestamps with GMT/BST or the device timezone abbreviation.
- Human-readable relative freshness and stale-data states.
- Redesigned dark-theme Cloud Refresh page with last run, next run, strategy, discovery and replay snapshots.
- Expandable UTC diagnostics rather than raw ISO timestamps in the main view.
- Risk-adjusted portfolio ranking using entry permission, health, recent P&L, drawdown, duration and capital efficiency.
- Explicit production-ready, forward-testing, deep-research and rejected classifications.
- Existing live-trading safeguards remain unchanged: no automatic bot, deal, DCA or production changes.

## Installation
Extract the ZIP directly inside the existing project folder and run `INSTALL_V26_EASY.bat`. Commit and push the installed files, then run the **V26 Autonomous Crypto Regime Refresh** workflow once.
