CRYPTO REGIME MANAGER V30.1 — EASY UPDATE

1. Close any command windows currently running the project.
2. Double-click INSTALL_V30_1_EASY.bat.
3. The installer backs up every replaced file under:
   C:\Crypto\Projects\.update-backups\V30_1_<timestamp>
4. After installation, commit and push the changes to GitHub.
5. Wait for GitHub Pages to redeploy, then refresh the Backtest Lab.
