# Crypto Regime Manager V14 — Candidate Intelligence Engine

V14 converts the winning autonomous research rule into a permanent, immutable candidate record.

## New capabilities
- Candidate registry with stable IDs and fingerprints
- Immutable frozen rule definition
- Explicit lifecycle from research to retirement
- Forward-test start set after the last candle known at freeze time
- Evidence graph linking the selected candidate to its sibling experiments
- No production, DCA, entry, exit or live-execution changes

Open `docs/candidates.html` after the workflow completes.
