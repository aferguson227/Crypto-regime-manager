# Updating to V10

1. Fetch and pull the latest repository in GitHub Desktop.
2. Preserve `.git`, `data`, and `threecommas_private_setup`.
3. Copy the V10 package files into the repository and replace matching files.
4. Commit with `Add Asset DNA Engine V10` and push.
5. Run `Update Crypto Regime Manager`.
6. Open `dna.html` after GitHub Pages refreshes.
