# Updating to V14

1. Fetch and pull your repository in GitHub Desktop.
2. Keep `.git`, `data`, and `threecommas_private_setup` unchanged.
3. Copy the V14 package into the repository and replace matching files.
4. Commit: `Add Candidate Intelligence Engine V14`.
5. Push and run **Update Crypto Regime Manager**.
6. Open `candidates.html`.

The first V14 run registers the current autonomous winner as `SUI-T1` (or reuses it if already registered), freezes its rule, and sets forward testing to begin after the last candle known at registration.
