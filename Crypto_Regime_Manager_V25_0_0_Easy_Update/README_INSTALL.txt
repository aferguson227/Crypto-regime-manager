CRYPTO REGIME MANAGER V25.0.0 EASY UPDATE

1. Extract the ZIP.
2. Move the extracted Crypto_Regime_Manager_V25_0_0_Easy_Update folder directly inside your existing Crypto Regime Manager project folder.
3. Double-click INSTALL_V25_EASY.bat.
4. Confirm the installer reports that all tests passed.
5. Commit and push the changes to GitHub.
6. Open GitHub Actions and manually run “V25 Autonomous Crypto Regime Refresh” once.
7. Confirm docs/cloud_status.json reports “healthy” and the app shows the cloud-refresh badge.

V25.0 adds laptop-independent scheduled refresh through GitHub Actions, a persistent cloud heartbeat, automatic browser checks for newly published snapshots, retry-safe publishing, and a Cloud Refresh status page.

The cloud process remains research/read-only. It cannot alter 3Commas bots, DCA settings, production strategies or live execution. Manual approval remains required.
